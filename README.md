# Estação Espacial Orbit

## Sobre a missão
Sistema de monitoramento e suporte de vida para a estação espacial, desenvolvido como atividade da disciplina de Garantia da Qualidade de Software.

## Linguagem utilizada
Python

## Camadas do ambiente
- **develop**: ambiente de desenvolvimento, onde novas funcionalidades são implementadas e testadas inicialmente.
- **stage**: ambiente de homologação, usado para validar as mudanças antes de irem para produção.
- **main**: ambiente de produção, contendo a versão estável e aprovada do sistema.
